# BodyZeal Fitness Application

BodyZeal is a fitness and workout logging application.

## Project structure

- `frontend/` contains the React + Vite application.
- `backend/` is reserved for the future backend and is intentionally empty.
- `.bolt/` contains the existing Bolt project metadata.

## Frontend development

```powershell
cd frontend
npm install
npm run dev
```

Other available frontend commands are `npm run build`, `npm run typecheck`, and `npm run lint`.
